# Shirt Reel Maker — NAS-এ বসানোর নিয়ম

টুলটা একটাই ফাইল (`site/index.html`, প্রায় ২০০ KB)। কোনো ডাটাবেস বা ইন্টারনেট সার্ভিস লাগে না। ছবি, ভিডিও, মিউজিক সব টিমের নিজের ব্রাউজারের ভেতরেই প্রসেস হয়, NAS-এ কিছু আপলোড হয় না। NAS শুধু পেজটা পরিবেশন করে।

## পদ্ধতি ১ (সবচেয়ে সহজ): Docker + nginx (OMV-তে)

1. NAS-এ একটা ফোল্ডার বানান, যেমন `/srv/dev-disk-by-.../apps/shirt-reel-maker/`
2. এই প্যাকের সব ফাইল সেখানে কপি করুন। ফোল্ডারের ভেতরে এমন থাকবে:
   ```
   shirt-reel-maker/
     docker-compose.yml
     nginx.conf
     site/index.html
   ```
3. OMV-তে Docker/Compose প্লাগিন থাকলে সেখান থেকে `docker-compose.yml` দিয়ে স্ট্যাক চালু করুন। অথবা SSH-এ (ইউজার `Ecotech`) এই ফোল্ডারে গিয়ে চালান:
   ```
   docker compose up -d
   ```
4. টিম ব্রাউজারে খুলবে:
   - Cudy নেটওয়ার্ক থেকে: `http://192.168.10.154:8089`
   - TP-Link নেটওয়ার্ক থেকে: `http://192.168.0.50:8089`

   পোর্ট 8089 অন্য কিছুতে ব্যবহার হলে `docker-compose.yml`-এর `"8089:80"` লাইনে প্রথম নম্বরটা বদলান।

## পরে আপডেট করার নিয়ম

নতুন `index.html` পেলে শুধু `site/index.html` ফাইলটা নতুনটা দিয়ে বদলে দিন (SMB দিয়ে কপি করলেই হয়)। কন্টেইনার রিস্টার্ট লাগবে না। `nginx.conf`-এ no-cache দেওয়া আছে, তাই টিমের সবাই পেজ রিফ্রেশ করলেই নতুন ভার্সন পাবে।

## পদ্ধতি ২ (Docker ছাড়া): SMB শেয়ারে ফাইল রেখে খোলা

`index.html` একটা শেয়ার ফোল্ডারে রাখুন, সবাই ফাইলটা ডাবল-ক্লিক করে Chrome/Edge-এ খুলুক। কাজ করে, তবে পদ্ধতি ১-এ সবার জন্য একটাই লিংক থাকে বলে সেটাই ভালো।

## টিমের জন্য জানা দরকার

- Chrome বা Edge (কম্পিউটারে) ব্যবহার করতে হবে। ভিডিও রেকর্ডিং রিয়েল-টাইমে হয়, তাই প্রতিটা ভিডিওর জন্য ১০ সেকেন্ড লাগে এবং রেকর্ড চলার সময় ট্যাবটা সামনে খোলা রাখতে হবে।
- ডাউনলোড করা ফাইল সাধারণ ব্রাউজার ডাউনলোড ফোল্ডারে যায়। "Download all as ZIP" দিয়ে একবারে সব নামানো যায়।
- ফন্ট গুগল থেকে আসে। অফিসের নেট বন্ধ থাকলে টুল ঠিকই চলবে, শুধু লেখার ফন্ট একটু সাধারণ দেখাবে।
