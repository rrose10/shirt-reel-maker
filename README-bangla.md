# Shirt Reel Maker: NAS-এ বসানো ও আপডেট

টুলটা একটাই ফাইল (`site/index.html`)। ছবি, ভিডিও, মিউজিক সব টিমের নিজের ব্রাউজারেই প্রসেস হয়। NAS পেজটা পরিবেশন করে, আর চাইলে তৈরি ভিডিও, মিউজিক লাইব্রেরি ও প্রিসেট জমা রাখে।

## চালু করা / আপডেট করা (NAS-এ SSH করে)

```
cd /shirt-reel-maker
sudo git pull
sudo docker compose down
sudo docker compose up -d
```

প্রথমবার চালু হলে কন্টেইনার নিজেই একটা https সার্টিফিকেট বানায় (ইন্টারনেট লাগে, ১ মিনিটের মতো)। `sudo docker logs shirt-reel-maker` দিয়ে দেখতে পারেন। শুধু `index.html` বদলালে `git pull` যথেষ্ট, রিস্টার্ট লাগে না।

## টিম কোন লিংকে খুলবে

| নেটওয়ার্ক | সাধারণ লিংক | নিরাপদ (https) লিংক, দ্রুত রেন্ডারের জন্য |
|---|---|---|
| Cudy | `http://192.168.10.154:8089` | `https://192.168.10.154:8443` |
| TP-Link | `http://192.168.0.50:8089` | `https://192.168.0.50:8443` |

**https লিংকটাই ব্যবহার করুন।** ব্রাউজার শুধু https পেজে দ্রুত ভিডিও তৈরির পদ্ধতি (WebCodecs) চালাতে দেয়। প্রথমবার ব্রাউজার "Your connection is not private" দেখাবে কারণ সার্টিফিকেট আমরা নিজেরা বানিয়েছি। **Advanced → Proceed to ... (unsafe)** চাপলেই চলে, প্রতি ব্রাউজারে একবারই। সাধারণ লিংকেও টুল চলে, তবে প্রতিটা ভিডিওর জন্য ১০ সেকেন্ড লাগে।

## NAS-এ কী জমা হয়

`Office` শেয়ারের ভেতরে `ShirtReels` ফোল্ডার নিজে তৈরি হয়:

- `ShirtReels/videos/<তারিখ>/` : তৈরি হওয়া প্রতিটা ভিডিও (টুলে "Also save every video to the office NAS" টিক থাকলে)।
- `ShirtReels/music/` : গানের লাইব্রেরি। এখানে গান রাখলে টুলের "Music library on the NAS" মেনুতে সবাই পাবে। টুল থেকে "Add to NAS library" চেপেও গান যোগ করা যায়।
- `ShirtReels/presets/` : প্রিসেট। একজন প্রিসেট সেভ করলে টিমের সবাই পায়।

NAS-এর এই অংশ শুধু NAS-এর লিংকে খুললে দেখা যায়। ফাইল খুলে সরাসরি চালালে (file://) বা Claude-এর ভেতরে দেখা যায় না, কিন্তু বাকি সবকিছু চলে।

## নিরাপত্তা

অফিস নেটওয়ার্কের যে কেউ `/nas/` এ ফাইল আপলোড করতে পারে (মুছতে পারে না)। বাইরের কেউ নয়, কারণ NAS ইন্টারনেটে খোলা নয়। ইন্টারনেটে খুলবেন না।

## ব্যবহারে কয়েকটা কথা

- Chrome বা Edge (কম্পিউটারে) ব্যবহার করুন।
- দ্রুত পদ্ধতিতে ভিডিও পিসির ক্ষমতা অনুযায়ী ১০ সেকেন্ডের চেয়ে অনেক কম সময়ে হয় এবং ট্যাব ব্যাকগ্রাউন্ডে থাকলেও চলে। কোনো কারণে না চললে টুল নিজে থেকে পুরনো পদ্ধতিতে (১০ সেকেন্ড, ট্যাব সামনে রেখে) ফিরে যায়।
- "Download all as ZIP" এর ভেতরে `captions.txt` থাকে, প্রতিটা ভিডিওর ক্যাপশন ও হ্যাশট্যাগসহ।


## AI video ট্যাব (Google Gemini)

এই ট্যাবে ডিজাইন থেকে AI দিয়ে মকআপ ছবি ও UGC-স্টাইল ভিডিও বানানো যায়। Google API key **শুধু NAS-এ** থাকে, ওয়েবপেজে কখনো যায় না।

NAS-এ একবার করুন:

1. `cd` করে `shirt-reel-maker` ফোল্ডারে যান (যেখানে `docker-compose.yml` আছে)।
2. `sudo git pull`
3. `cp .env.example .env` তারপর `.env` ফাইল খুলে `GEMINI_API_KEY=` এর পরে নিজের key বসান। (`.env` গিটে আপলোড হয় না।)
4. `sudo docker compose up -d` (এতে নতুন `ai-proxy` কন্টেইনার চালু হবে)।
5. ব্রাউজারে Ctrl+F5 দিয়ে **AI video** ট্যাব খুলুন। নিচে "Videos today: 0 of 30" দেখালে সব ঠিক আছে।

খরচের সুরক্ষা: দিনে সর্বোচ্চ ৩০টা ভিডিও ও ১০০টা ছবি (`.env`-এ `AI_DAILY_LIMIT`, `AI_DAILY_IMAGE_LIMIT` দিয়ে বদলানো যায়)। প্রতিটা ভিডিও শেষ হলে `Office/ShirtReels/videos`-এ নিজে সেভ হয়।
